
# Unified Customer Complaint Communication Dashboard

## About
A Gen-AI powered platform that collects customer complaints
from multiple channels and provides intelligent insights.

## Key Features
- Centralized complaint management
- AI-based complaint classification
- Sentiment and severity analysis
- Duplicate complaint detection
- AI-powered resolution suggestions
- SLA tracking
- Analytics dashboard

## Technology Stack
- Frontend: Streamlit
- Backend: Python, FastAPI
- Database: SQLite
- AI: LLM API
- Version Control: Git and GitHub
- Deployment: Docker and Azure
